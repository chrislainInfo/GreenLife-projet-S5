# GreenLife-projet-S5

Site vitrine pour une association écologique dédiée à la reforestation et à la préservation de l'environnement. Projet réalisé en HTML/CSS, mettant en avant une structure sémantique, une mise en page responsive utilisant Flexbox, CSS Grid et Media Queries, ainsi qu'une gestion rigoureuse via Git et GitHub

## Groupe

**Nom du groupe :** Green Life
**Thème :** Environnement (reforestation et préservation)
